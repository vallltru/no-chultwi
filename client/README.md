# Client

No Chultwi의 사용자용 및 관리자용 React 애플리케이션을 관리하는 프론트엔드 워크스페이스입니다.

## 구조

- `apps/user`: 사용자용 애플리케이션
- `apps/admin`: 관리자용 애플리케이션
- `packages/ui`: 공통 UI 컴포넌트
- `packages/api-client`: 공통 API 클라이언트
- `packages/eslint-config`: 공통 ESLint 설정
- `packages/tsconfig`: 공통 TypeScript 설정

패키지 매니저와 실행 방법은 프로젝트 초기화 후 추가합니다.
